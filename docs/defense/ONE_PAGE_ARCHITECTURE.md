# Architecture in one page

Location → validated service-region coordinates → cache/lease/budget → bounded provider adapters → unit/provenance checks → shared index engine → source-labelled current/tomorrow payload → browser response validation → environmental advisory. Optional weather/fire failures are disclosed. No validated experimental correction is deployed. Research archive/model selection is a separate process.

Python supplies provider orchestration and APIs; Next.js supplies UI; Postgres/Supabase supplies cache, quotas, snapshots and immutable prospective ledgers. Native forecast cells are around 40 km. The API can return 202 for queued work, 429 for budgets, 400 for invalid input or 503 for unavailable data.
