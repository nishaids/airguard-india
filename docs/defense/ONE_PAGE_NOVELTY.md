# Novelty in one page

Defensible addition: an auditable integration of Indian station targets, a shared CPCB-style engine, explicit issue-time rules, temporal/spatial/severity evaluation and exposure-advisory trade-offs. This is an engineering and validation contribution under investigation, not a proven new atmospheric model. Bias correction, conformal prediction and pollution advisories already exist in research.

CAMS supplies the atmospheric forecast. OpenAQ distributes upstream measurements. AirGuard owns the integration, QC, provenance, index transformation and evaluation code. Correction superiority and vulnerable-cohort benefit remain unproved. Never say ‘world first’ or ‘more accurate than CAMS’ yet.
