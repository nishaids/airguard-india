# AirGuard jury and viva defense index

Start with ONE_PAGE_PROJECT, ONE_PAGE_RESULTS and CLAIM_EVIDENCE_MATRIX. This pack is a checkpoint defense of actual implementation/evidence, not a research paper or a claim that all experiments finished.

## Launch a local demo

From the repository root, in two terminals:

```powershell
.\.venv-live\Scripts\python.exe -m webapp.dev_api_server --port 8787
```

```powershell
cd webapp
npm run dev -- --hostname 127.0.0.1 --port 3000
```

Open http://127.0.0.1:3000/live. Use the configured private server environment; never print it. Choose an already checked place, rehearse live source states and use DEMO_FAILURE_MODE if a provider fails. No experimental correction deployment is included.
