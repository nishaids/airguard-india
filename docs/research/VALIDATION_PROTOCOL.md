# VALIDATION PROTOCOL

Split globally by target date, keeping all stations on a date together. Predeclare 90 training dates, 30 calibration dates, 30 test dates and a one-day embargo at each boundary. Prior outcomes must be available before the following partition's first issuance. Report expanding and bounded rolling windows separately. Latest 30 dates are locked final test; choose A0–A4 on earlier expanding folds only. Fixed estimator hyperparameters avoid final-test tuning. Leave-city and leave-station out are time-ordered. Report n for every subgroup. This complete design needs at least 182 distinct eligible target dates for one validation fold plus the separate final test. Seven-day paired moving-block bootstrap preserves all station pairs on each resampled date; no DM p-value is invented.
