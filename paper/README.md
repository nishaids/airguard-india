# Unsubmitted research draft

`main.tex` is IEEE conference-class source. It is a draft, not a submission: it
reports no accuracy, interval-coverage or health result, because none exists
yet, and its own abstract says so.

## What is generated, and by what

Nothing in the manuscript is typed by hand.

| Input | Generated by |
| --- | --- |
| `refs.bib` | `make refs` — fetched from Crossref, the arXiv API and official publisher pages, each entry checked against an expected title; anything that fails is dropped and the reason recorded in `results/reference_verification.json`. |
| `tables/evidence.tex` | `make tables` — each row names the artefact and key it was read from. |
| `tables/hai_factors.tex` | `make tables` — from `config/hai_factors.yaml`, so the table cannot show a coefficient the register has not adopted. |
| `figures/evidence_coverage.pdf` | `python -m src.research.reproduce figures` — from real coverage counts. |

`make rules` checks the call's format rules statically and writes
`results/paper_rules.json`. It currently fails exactly one check, author
placeholders, which is a human action. Page count and embedded fonts need a
LaTeX run; no TeX toolchain is installed here.

`make paper` deliberately fails while `results/evidence_index.json` reports
`paper_submittable: false`. A compiled PDF built from empty inputs would look
like a finished study, which is the one thing this draft must not do.

## Before submitting

Work through `CHECKLIST.md`. The blocking items are author details, a chosen
conference and its CFP, a qualified review of any health coefficient, and
empirical results that depend on archived forecasts and elapsed prospective
days.

## The article

The Medium article lives at `../article/medium.md`, written in fresh prose.
`make article` asserts that it shares no run of eight or more words with the
manuscript and that it sits in the 1,200-1,800 word range, so publishing it
cannot put the paper's own sentences into a public page ahead of a similarity
check. Do not publish it before the submission milestone.
